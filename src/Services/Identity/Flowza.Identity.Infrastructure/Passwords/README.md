# Common-password list

`common-passwords.txt` is the public top-10,000 list `Passwords/Common-Credentials/10k-most-common.txt` from
[SecLists](https://github.com/danielmiessler/SecLists) (MIT License, Copyright (c) 2018 Daniel Miessler), copied
unchanged on 2026-10-21. It is embedded in the assembly; nothing is fetched at run time (plan 001, PA7).

New passwords on this list are rejected (IAM-06), ignoring letter case.
